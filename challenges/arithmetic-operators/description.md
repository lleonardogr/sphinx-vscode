# Arithmetic Operators

Read two whole numbers `a` and `b` and print the result of each arithmetic operator.

**Input**

One line with two integers `a` and `b` (`b` is never 0).

**Output**

Five lines, in this exact format (example for `7 3`):

```
7 + 3 = 10
7 - 3 = 4
7 * 3 = 21
7 / 3 = 2
7 % 3 = 1
```

**Things to know**

- `/` between two `int` values is **integer division**: the decimal part is dropped.
- `%` (modulo) gives the **remainder** of the division.
