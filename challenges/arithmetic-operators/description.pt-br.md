# Operadores aritméticos

Leia dois números inteiros `a` e `b` e imprima o resultado de cada operador aritmético.

**Entrada**

Uma linha com dois inteiros `a` e `b` (`b` nunca é 0).

**Saída**

Cinco linhas, exatamente neste formato (exemplo para `7 3`):

```
7 + 3 = 10
7 - 3 = 4
7 * 3 = 21
7 / 3 = 2
7 % 3 = 1
```

**O que você precisa saber**

- `/` entre dois valores `int` é **divisão inteira**: a parte decimal é descartada.
- `%` (módulo) dá o **resto** da divisão.
