# Inverter uma String

Leia uma linha de texto e imprima ela **de trás para frente**.

**Entrada**

Uma linha de texto (pode ter espaços).

**Saída**

O mesmo texto, invertido.

**O que você precisa saber**

- `IO.readln()` lê uma linha inteira, inclusive os espaços. (Java clássico: `scanner.nextLine()`.)
- `text.length()` é o número de caracteres, e `text.charAt(i)` é o caractere na posição `i`.
