# Count to N

Read a number `n` and print every number from `1` to `n`, one per line.

**Input**

An integer `n` (1 ≤ n ≤ 1000).

**Output**

The numbers 1, 2, …, n, each on its own line.

**Things to know**

- `for (int i = 1; i <= n; i++) { … }` repeats the block with `i` going 1, 2, …, n.
- The three parts are the start (`int i = 1`), the condition to keep going (`i <= n`) and the step (`i++`).
- `IO.println(i)` inside the loop prints one number per line.
