# Contar até N

Leia um número `n` e imprima todos os números de `1` até `n`, um por linha.

**Entrada**

Um inteiro `n` (1 ≤ n ≤ 1000).

**Saída**

Os números 1, 2, …, n, cada um na sua linha.

**O que você precisa saber**

- `for (int i = 1; i <= n; i++) { … }` repete o bloco com `i` indo de 1, 2, …, até n.
- As três partes são o início (`int i = 1`), a condição para continuar (`i <= n`) e o passo (`i++`).
- `IO.println(i)` dentro do laço imprime um número por linha.
