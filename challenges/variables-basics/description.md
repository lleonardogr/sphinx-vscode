# Greeting with Variables

Read a person's **name** and **age**, store them in variables, and print a greeting.

**Input**

- Line 1: a name (a single word)
- Line 2: an age (a whole number)

**Output**

```
Hello, <name>!
Next year you will be <age + 1> years old.
```

**Things to know**

- A `String` variable holds text, an `int` variable holds a whole number.
- `IO.readln()` reads one line as a `String`, and `Integer.parseInt(text)` turns text like `"36"` into an `int`. (Classic Java: `scanner.next()` and `scanner.nextInt()`.)
