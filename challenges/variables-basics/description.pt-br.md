# Saudação com variáveis

Leia o **nome** e a **idade** de uma pessoa, guarde em variáveis e imprima uma saudação.

**Entrada**

- Linha 1: um nome (uma única palavra)
- Linha 2: uma idade (um número inteiro)

**Saída**

```
Hello, <nome>!
Next year you will be <idade + 1> years old.
```

**O que você precisa saber**

- Uma variável `String` guarda texto, e uma variável `int` guarda um número inteiro.
- `IO.readln()` lê uma linha como `String`, e `Integer.parseInt(texto)` transforma um texto como `"36"` em `int`. (Java clássico: `scanner.next()` e `scanner.nextInt()`.)
