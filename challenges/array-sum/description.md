# Array Sum

Read `n` numbers into an array and print their sum.

**Input**

- Line 1: an integer `n`, the number of elements (1 ≤ n ≤ 100)
- Line 2: `n` integers separated by spaces

**Output**

The sum of all the numbers.

**Things to know**

- `int[] numbers = new int[n];` creates an array with room for `n` integers.
- Positions (indexes) go from `0` to `n - 1`, and `numbers.length` is the size.
