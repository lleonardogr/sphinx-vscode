# Soma de um array

Leia `n` números para dentro de um array e imprima a soma deles.

**Entrada**

- Linha 1: um inteiro `n`, a quantidade de elementos (1 ≤ n ≤ 100)
- Linha 2: `n` inteiros separados por espaços

**Saída**

A soma de todos os números.

**O que você precisa saber**

- `int[] numbers = new int[n];` cria um array com espaço para `n` inteiros.
- As posições (índices) vão de `0` a `n - 1`, e `numbers.length` é o tamanho.
